# フォームをスプレッドシートに繋ぐ

`contact.html`（お問い合わせ）と `brief.html`（ご依頼フォーム）の入力内容を
Google スプレッドシートに記録し、通知メールを送る設定です。
サーバーは不要、所要時間は10分ほどです。

設定していない状態でも、フォームは**メールソフトを開くフォールバック**で動きます。
ただし記録は残らないので、公開前に設定してください。

## できるようになること

| | |
|---|---|
| お問い合わせ | `contacts` シートに1行追加 → info@ichi-pj.com へ通知 |
| ご依頼フォーム | `briefs` シートに1行追加 → info@ichi-pj.com へ通知 |
| 送信者へ | 「承りました」の受付メールが自動で届く（金額は書きません） |
| 通知メール | そのまま送れる**返信の下書き**が付いてきます |

---

## 手順

### 1. スプレッドシートを作る

新しいスプレッドシートを作り、URLからIDを控えます。
シートのタブは作らなくて構いません（`contacts` と `briefs` は自動で作られます）。

```
https://docs.google.com/spreadsheets/d/【ここがID】/edit
```

### 2. Apps Script を開く

そのスプレッドシートで **拡張機能 → Apps Script**。
エディタの中身を全部消して、`gas/Code.gs` の内容をそのまま貼り付けます。

### 3. スプレッドシートIDを登録する（初回だけ）

**`Code.gs` は書き換えません。** スプレッドシートのIDは Apps Script 側に登録します。

1. エディタ左の歯車 **「プロジェクトの設定」** を開く
2. 下の **「スクリプト プロパティ」** → 「スクリプト プロパティを追加」
3. プロパティ名 `SHEET_ID`、値に手順1で控えたIDを貼って保存

**なぜファイルに書かないか。** このリポジトリは公開されているため、IDを
`Code.gs` に書くと git の履歴に残り続けます。IDだけでシートは開けませんが、
共有設定が一度でも「リンクを知っている全員」になると、問い合わせ全件
（氏名・メール・電話番号）が読める状態になります。

スクリプトプロパティに入れておけば、**`Code.gs` を貼り直しても消えません。**
コードを更新するときは、エディタの中身を全部消して貼り直すだけで済みます。

`SECRET` と `NOTIFY_TO` は `Code.gs` に書いたままで構いません。SECRET は
ブラウザ側のソースにも出るため秘密ではなく、いたずら送信を減らすための印です。

### 4. 動作確認

エディタ上部の関数選択で **testAppend** を選んで「実行」。
初回は権限の確認が出るので許可します（「詳細」→「安全でないページに移動」で進みます）。
シートに1行入れば成功です。

### 5. デプロイ

**デプロイ → 新しいデプロイ** → 歯車から種類 **ウェブアプリ** を選びます。

| 項目 | 設定 |
|---|---|
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** |

発行される `https://script.google.com/macros/s/.../exec` をコピーします。

> 「全員」にしないとフォームから送信できません。
> SECRET が合わない投稿はスクリプト側で弾くので、URLを知られても書き込みはできません。

### 6. サイト側に貼る

`build.py` の上のほうにある **FORM_ENDPOINT** に、手順5のURLを入れます。
**ここ1箇所だけ**です。ビルド時に両方のフォームへ自動で入ります。

```python
FORM_ENDPOINT = "https://script.google.com/macros/s/.../exec"
```

そのあとビルドします。

```
python3 build.py
```

### 7. 送信テスト

```
python3 -m http.server -d dist 8000
```

http://localhost:8000/contact.html から自分宛に送信し、

- スプレッドシートの `contacts` に行が増えたか
- info@ichi-pj.com に通知が届いたか
- 送信に使ったアドレスに受付メールが届いたか

の3つを確認してください。

## つまずきやすいところ

**送信しても何も起きない**
FORM_ENDPOINT を入れたあとビルドし直しましたか。`dist/` は毎回作り直されます。

**「承認されていません」と出る**
手順5の「アクセスできるユーザー」が **全員** になっているか確認してください。

**シートに列が足りない**
先にシートを作ってしまうと、あとから項目を増やしても列は自動追加されません。
該当シートのタブを削除して送信し直せば、正しい見出しで作り直されます。

## Code.gs を直したとき

保存しただけでは反映されません。
**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ**
を実行してください。URLは変わりません。

## 仕様メモ

- 送信は `Content-Type: text/plain` で行っています。CORSのプリフライトを避けるためで、
  Apps Script のウェブアプリではこれが最も安定します。
- `SECRET` はブラウザ側のソースに出るため、**秘密ではありません**。
  いたずら投稿を減らすための最低限の仕切りです。
  本格的に防ぐなら reCAPTCHA か Cloudflare Turnstile を挟んでください。
- 自動返信メールに**金額は書きません**。契約書で確定的な金額・納期を保証しないと
  定めているため、金額は人の判断で返します。
