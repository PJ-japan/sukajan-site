用途から探す

スカジャンは「誰に、何のために作るのか」で柄が変わります。これまでにお受けしてきたのは、次のような用途です。ここにない用途でも構いません。

フルオーダー一着

個人のお客様の一点物。入れたいモチーフをうかがって柄から描き起こします。オーダーメイドについて

ブランド別注

アパレルブランドとの協業。1着の試作から100着以上の量産まで。スカジャンOEMについて

アーティストグッズ

ライブ・ツアー物販。ステージ衣装と物販を揃えた柄でお作りすることもできます。

周年・記念品

創業記念、退職記念、還暦。社史や思い出の意匠を柄に組み込みます。

駐留記念

米軍関係者向けのスーベニア。部隊名や滞在した年を入れた、スカジャン本来の使われ方です。

インバウンド商材

観光・土産物向け。海外のお客様に向けた柄と、まとまった数の生産に対応します。

今すぐ自動見積もり 用途を相談する

HOW TO書き方

1件 = JSONの1ブロック。

事例の足しかた

01

画像を置く

assets/works/ に jpg を置きます。書き出しの前に sRGB に変換してください。Display P3 のままだと色が転びます。image を空にすると点線の枠になるので、写真が未定でも書き溜められます。

02

works.json の先頭に足す

"draft": true を付けている間は、このページにだけ出ます。

03

title に柄の名前を入れる

検索で探されるのは柄の名前です。「鵺（ぬえ）」「蠍座／M-43」のように、固有の柄名を必ず含めてください。「オーダースカジャン」だけでは埋もれます。

04

掲載許諾を確認する

ブランド案件は案件ごとに掲載可否が違います。公開前に必ず確認してください。

05

draft を消して公開

"draft": true の行を消して python3 build.py。works.html とトップに出ます。

記入例：
{ "title": "鵺（ぬえ）／JAPAN／オリジナルスカジャン", "meta": "オリジナル柄／黒ボディ／背中一面", "image": "assets/works/nue-japan.jpg", "url": "https://...", "draft": true }
